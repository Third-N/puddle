水たまり
ゼロ東京

雨の日も、濡れにくい道を。
東京の地形データから水たまりを予測し、
避けて歩けるルートを出します。

Team Third N 背景 — 国土地理院 DEM5A による陰影起伏

課題

地図は「最短」しか
教えてくれない。

雨の日に靴を濡らすのは、いつも決まった場所です。少しくぼんだ交差点、水が集まる歩道のへり。そこを通るかどうかで、目的地に着いたときの状態が変わります。

水たまりができる場所は、地形でほぼ決まります。データはすでに公開されているのに、それを歩く人に返す地図がありません。

歩行者向けの経路案内は、距離と時間だけを最適化しています。

つくったもの

2本のルートを、
並べて見せる。

出発地と目的地を地図で選ぶと、通常の最短ルートと、水たまりができそうな地点を避けたルートを同時に描きます。

何分よけいにかかり、そのぶん危険度がどれだけ下がるのか。遠回りする価値があるかを、その場で判断できます。

最短ルート 水たまり回避ルート 危険地点

地点は駅名・施設名でも探せます（OSMから865件）。出した結果はURLで共有でき、リンクを送れば同じ比較がそのまま開きます。

どうやって当てるか

水の集まる場所は、
地形から計算できる。

01 — 地形を読む

標高から地形指標を出す

窪地の深さ、雨水の流域面積、傾斜、周囲との高低差。

02 — 危険度にする

指標を1枚の地図に合成

「水が集まる度合い」と「水がはけない度合い」の積として表す。

03 — ルートに落とす

道のコストに織り込む

危険な区間を「長い道」として扱い、避ける経路を選ばせる。

推定はすべて事前に計算して持っておきます。検索のたびに外部サービスを呼ぶことはありません。

01 — 地形を読む

5mメッシュの標高で、
街の凹凸を見る。

国土地理院の DEM5A（航空レーザ測量による5mメッシュ標高）を対象地域ぶん取得し、488×443のグリッドに整えます。

  • 窪地の深さ — 窪地を埋める処理をかけ、埋める前との差を取る。そこに溜まりうる水深にあたる。
  • 流域面積 — 最急降下方向をたどり、どれだけの範囲の雨水がそのセルへ集まるかを積み上げる。
  • 傾斜 — 水がはけるかどうか。

02 — 危険度にする

掛け算にすると、
道ごとの差が出た。

危険度 = (水が集まる度合い) × (水がはけない度合い) 水が集まる = 0.42×窪地 + 0.38×流域 + 0.20×高低差 水がはけない = 0.65 + 0.35×平坦さ

最初は4つの指標の重み付き和で作りました。ところが都心は全体が平坦なため、傾斜の項が全区間に同じ下駄を履かせ、危険度が0.2前後に潰れてしまいました。傾斜を加算から倍率に移した結果、中央値0.02／最大0.99まで広がり、道ごとの差が出るようになりました。

図の街路が浮かび上がって見えるのは、雨水が実際に道に沿って集まるためです。

検証

東京都の浸水予想と、
同じ場所を指した。

東京都下水道局が公開している「浸水予想区域図（改定）浸水深・地盤高」と突き合わせました。対象地域内の 26,154点 で照合しています。

4.7倍 危険度が上位10%の地点は、都の予想で
10cm以上浸かる割合が 44.8% ／ それ以外 9.6%

入力そのものの確認として、都の地盤高と国土地理院DEM5Aの相関は r = 0.921、中央絶対差 10cm でした。

照合したのは地形だけから出した危険度です。実際のルート探索では、そこに都の予想を重ねた値を使っています。重ねた値で照合すると、答えを見てから答え合わせをすることになるためです。

浸水が深いほど危険度も上がります。ただし0〜10cmは「浸水なし」と区別がついていません。都のデータが表すのは街区が冠水する規模で、私たちが狙う歩道の水たまりとは尺度が違うためです。一致するのは場所であって、深さではありません。

03 — ルートに落とす

危険な道を、
長い道として扱う。

OpenStreetMapの歩ける道でグラフを作り、同じダイクストラ法を、コスト関数だけ替えて2回まわします。

最短ルート cost = 距離 回避ルート cost = 距離 × (1 + 4.0 × 実効危険度)

実効危険度は、区間の危険度に雨量の倍率（弱雨 0.55 ／ 中雨 1.00 ／ 強雨 1.45）を掛けたものです。同じ道でも、強い雨ほど避ける対象になります。

危険度（%）が意味するもの

区間の遭遇率 = min(1, 危険度 / 0.35) × 区間長 / 500m 危険度 = 1 − exp(−Σ 区間の遭遇率)

画面に出る「危険度 64%」は、そのルートを歩いて水たまりに出くわす推定確率です。地形スコアの平均にすると、ほとんど安全だが一箇所だけ深刻なルートが薄まってしまうため、区間ごとの遭遇率を距離で積み上げる形にしました。同じ危険度の道でも、長く歩けばそれだけ出くわしやすくなります。

これから

いま言えること、
まだ言えないこと。

危険度は地形だけからの推定です。排水設備や舗装材、実際の冠水履歴は見ていません。絶対値ではなく、同じ地域の道どうしの相対比較として読むのが正しい数字です。

標高は地表面のデータなので、高架下や地下道など立体交差の扱いは正確ではありません。対象地域もデモ用に絞っています。

次にやること

  • アメダス等の実況雨量と連携し、3段階固定をやめる
  • 都の浸水予想を、検証だけでなく危険度そのものに織り込む
  • 対象地域を広げる
  • 利用者からの「ここは溜まる」という投稿で補正する

地形は変わりませんが、街は変わります。実測と投稿を足していけば、推定は現実に寄っていきます。
