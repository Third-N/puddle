# frontend — 水たまりゼロ東京

React + TypeScript + Vite + MapLibre GL JS。

## セットアップ

```bash
npm install
npm run dev
```

バックエンド（`backend/`）を `http://localhost:8000` で起動しておいてください。
`vite.config.ts` のプロキシで `/api` がそちらへ転送されます。

`npm run build` で型チェック込みの本番ビルドができます。

## できること

- 地図をクリックして出発地→目的地を選択（1回目のクリックが出発地、2回目が目的地。
  目的地選択後にもう一度クリックすると出発地からやり直せます）
- 弱雨・中雨・強雨の切り替え（切り替えると再検索します）
- 「ルートを検索」で最短ルート（灰）と水たまり回避ルート（緑）を比較表示
- 危険地点（赤〜黄のヒートマップ＋丸マーカー）をクリックすると判定理由を表示
- 検索中／エラー時の表示
- 「選択をリセット」で最初からやり直し
- 選んだ地点に「東京駅」「アーティゾン美術館 付近」のような名前を表示
  （バックエンドの `/api/place`。取れなければ座標表示に落とす）
- デモ対象地域の外側を薄く覆って、使える範囲がひと目で分かるように表示
- 迂回しても危険度が下がらない区間では、そう明示する
- 画面を開いた時点でバックエンドの生死を確認し、落ちていれば先に知らせる

## 構成

```
src/
├── App.tsx                 画面全体の状態管理（出発地・目的地・雨量・検索結果など）
├── api/
│   └── client.ts            ★バックエンドへの唯一の入り口
├── components/
│   ├── SearchPanel.tsx      左側の入力・結果パネル
│   └── MapView.tsx          MapLibreの地図・ルート線・危険地点・ポップアップ
├── data/
│   └── places.ts            地図の初期表示位置と、地点名の簡易ラベル付け
├── utils/geo.ts             距離計算などの地理計算ユーティリティ
└── types.ts                 共通の型定義
```

## バックエンドとの接続

`src/api/client.ts` の `fetchSearchResult()` が `POST /api/route` を呼びます。
呼び出し元は `App.tsx` の `runSearch` の1箇所だけです。

レスポンスは `src/types.ts` の `SearchResult` と同じ形で返ってきます。
バックエンド側のスキーマは `backend/app/models.py` にあり、両者は1対1で対応しています。
**片方を変えたら必ずもう片方も合わせてください。**

エラー時、バックエンドは `{"detail": "日本語のメッセージ"}` を返します。
`client.ts` がそれを取り出して `ApiError` にし、`App.tsx` がそのまま画面に表示します。

雨量を切り替えると検索が走り直すため、`runSearch` では直前のリクエストを
`AbortController` で中断し、さらに通し番号でも古い応答を弾いています。

### APIの向き先を変える

別ホストのバックエンドを見るときは `.env.local` に次を書きます。

```
VITE_API_BASE_URL=https://example.com/api
```

未設定なら `/api`（開発時はViteのプロキシ経由）を使います。

## 地図について

ベースマップ（`MapView.tsx` の `MAP_STYLE`）はCARTOの無料タイルです。
必要に応じて東京都のベースマップ等に差し替え可能です。

危険地点の判定に国土地理院の標高タイルを使っているため、
地図の attribution に「標高: 国土地理院」を入れてあります。出典表示は消さないでください。
