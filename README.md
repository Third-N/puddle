# 水たまりゼロ東京 / Puddle Twin Tokyo

都知事杯オープンデータ・ハッカソン2026 提出プロジェクト。

雨の日に歩道にできる水たまりを予測し、「最短ルート」と「水たまり回避ルート」を
地図上で比較できるWebアプリです。

## リポジトリ構成

```
puddle-twin-tokyo/
├── frontend/   React + TypeScript + Vite + MapLibre
└── backend/    Python + FastAPI（地形解析・危険度推定・ルート探索）
```

## 現在の状態

フロントとバックエンドは接続済みで、通しで動きます。

- `frontend/` : 地図クリックで出発地・目的地を指定 →「ルートを検索」でバックエンドの
  `POST /api/route` を呼び、最短ルート（灰）・回避ルート（緑）・危険地点を描画します。
  弱雨／中雨／強雨の切り替え、危険地点クリックでの判定理由表示に対応しています。
  選んだ地点には駅名・施設名を表示し、デモ対象地域の範囲も地図上に示します。
  駅名・施設名での検索と、URLでの結果共有に対応しています。
- `backend/` : 国土地理院の標高タイル（DEM5A・5mメッシュ）から窪地・流域・傾斜を計算して
  水たまりの危険度を推定し、OpenStreetMapの歩行空間ネットワーク上でダイクストラ法により
  2種類のルートを返します。さらに東京都下水道局の浸水予想区域図を重ね、
  行政のシミュレーションによる裏づけを加えています。固定データではなく実データで動いています。

## セットアップと起動

ターミナルを2つ使います。

**1. バックエンド**

```bash
cd backend
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
.venv/bin/uvicorn app.main:app --reload --port 8000
```

**2. フロントエンド**

```bash
cd frontend
npm install
npm run dev
```

http://localhost:5173 を開きます。`/api` へのリクエストは Vite のプロキシ経由で
`http://localhost:8000` に転送されるので、CORSの設定は不要です。

バックエンドが読む生成データ（`backend/data/generated/`）はコミットしてあるため、
初回でも取得処理を待たずに起動できます。作り直したいときは
`backend/scripts/build_data.py` を実行してください。

## デモ対象地域

東京駅〜有楽町駅〜日比谷〜京橋の周辺（`35.6700,139.7570` 〜 `35.6870,139.7760`）。
この範囲の外を指定すると、その旨のエラーが表示されます。

## 使っているオープンデータ

| データ | 出典 |
| --- | --- |
| 標高タイル DEM5A（5mメッシュ） | 国土地理院 |
| 浸水予想区域図（想定浸水深・地盤高） | 東京都下水道局 |
| 道路データ・施設名 | OpenStreetMap contributors（ODbL） |
| ベースマップ | CARTO |

## 分かっていること

対象地域内の400経路で試した結果（中雨）:

- 危険度が3ポイント以上下がる経路 … **92.8%**
- 10ポイント以上下がる経路 … **72.5%**（下がり幅の中央値 16ポイント）
- そのための遠回り … 中央値 **44m / 1分**、うち **41.8%** は所要時間が変わらない
- 都の浸水想定区間との重なり … 最短 20.4% → 回避 **10.1%**

`backend/scripts/measure_impact.py` で再現できます。
